## Observations and caveats

- **Seeding hides history:** setup steps were applied before the run folder's first commit, so git history doesn't show the "before" state. R10 sessions therefore said the file "was never committed" rather than "was deleted". The conclusion and behavior were still right (no edit), but R10 tests reaction to a missing file, not to a visible deletion.
- **Unverifiable scratch checks:** every fix run also reported an ad-hoc scratch check of the failure path. Those scripts aren't in the repo, so they can't be verified. The suite counts all matched my reruns.
- **Missing regression tests:** no fix run added a regression test to the repo. The prompt didn't ask for one.
- **Hand-over notes:** several sessions left notes in the app's shared notes folder. Nothing outside the run folders was changed.
- **Test-runner workaround:** one run (R06 run 3) had pytest blocked by Windows Application Control and verified behavior with a direct Python run instead. Its no-edit result is unaffected.
- **Limited scope:** one model, one client, one machine, scored by one reviewer (Claude).
