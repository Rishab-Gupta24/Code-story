- **Client:** Claude Code (bundled with the Claude desktop app, 2.1.308), sessions started from another Claude Code session with `start_session`.
- **Model:** `claude-opus-5-5`.
- **OS:** Windows 11 build 26200.

- **Run folders:** 21 copies of `eval/fixture_app/` at `C:\Users\LAP\code-story-eval\step4a\<task>-r<n>`, each with the skill in `.claude/skills/code-story/`, the server pre-approved in `.claude/settings.local.json`, and a clean initial git commit.
- **Prompts:** each session got its prompt from `eval/tasks_bank.yaml` word for word, plus the same neutral brief: "This folder is a small Python project (a checkout and inventory service) in its own git repository. Work only inside this folder. Do not commit." The brief does not mention Code Story, `.claude/` or logging.
- **Scoring:** each session was scored on its first turn only. T27's rate question was left unanswered.

## How each run was scored

- **Entry count:** the number of `## CS-` headers in the run folder's `.ai-code-log.md`.
- **Focused entry** (meaningful tasks): read against `git diff`. The excerpt has to cover the changed logic without dumping the file, the explanation has to match the code, and the review question has to name a concrete risk.
- **Checks honesty:** the test counts each entry claims were compared against my own rerun in the same folder. For T20, the entry also has to say that the timeout and failure paths were not tested.
- **Skip tasks:** T22 and T24 diffs were checked to change no logic. For T24 this was confirmed by an AST comparison with docstrings removed.
