## Harness notes and caveats

- **Fullwidth at sign:** the session launcher rewrites a literal at sign in prompts to fullwidth "＠" (U+FF20). T21 run 1 received "＠". The session noticed, used the ASCII "@", and raised it in its review question. Runs 2 and 3 used the bank's new wording ("an at sign"), and the code they wrote has an ASCII "@".
- **Trust prompts:** the first attempt to start run 1 lost 10 sessions to trust-prompt collisions. Those 10 were started again one at a time, unchanged.
- **Second turns:** T29 run 1 and T30 run 1 got a second user message typed in their own sessions. Turn-1 scores are unaffected. In T29's second turn, the session implemented full multi-currency conversion, a completed meaningful change, and did not log it. The task bank has no test for logging after a back-and-forth.
- **Unverifiable stash claims:** several entries say the session stashed the fix and saw its new test fail. Transcripts don't show command text, so those claims can't be verified. Every claim that could be checked was correct.
- **Limited scope:** one model, one client, one machine, scored by one reviewer (Claude) against the answer key.
